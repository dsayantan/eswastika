# Swastika Watch

Index of CPIM leaders mentioned in the RSS weekly Swastika (eswastika.com), with links to the exact PDF page.
Open `index.html` (GitHub Pages). Data lives in `data/mentions.js` and is regenerated every Sunday.

`hindutva.html` — Hindutva programs and propaganda lines in every 2026 issue (per-issue summaries plus a year overview),
generated from the OCR text by Claude (`tools/hindutva_summarize.sh`, `tools/hindutva_overview.sh`). Data: `data/hindutva.js`.
New issues are summarised by the Sunday cron; existing summaries are never redone.
